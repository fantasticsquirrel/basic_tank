# Basic Tank Control

Expo/React Native controller for `basic_tank`. It connects directly to the ESP32 on local Wi-Fi and provides Auto/Manual selection, telemetry, independent track controls, and an explicit stop control.

```sh
npm install
npm run typecheck
npm run web
```

See [`../docs/WIFI_CONTROL.md`](../docs/WIFI_CONTROL.md) for setup, protocol details, safety behavior, and APK builds.
